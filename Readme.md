## Описание

RMOK-GUI является графическим пользовательским интерфейсом, предназначенным для работы с API RMOK-API и системой телефонии.

## Требования

- Node 14.19.3

## Установка

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/<ссылка на репу>/rmok.git
cd rmok.gui
```


### Шаг 2: Настройка переменных сред

Для разработки определять переменные среды нет необходимости!


### Шаг 3: Установка зависимостей

На данном этапе устанавливаются зависимости проекта.

```bash
npm i
```


### Шаг 4: Создание базы данных и загрузка "fixtures"

На данном этапе выполняется следующие процедуры:

- создания базы данных
- создание схемы
- загрузка "fixtures" (тестовых данных).

```bash
npm run serve
```
